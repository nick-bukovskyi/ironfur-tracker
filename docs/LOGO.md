## In-game icon and screenshots

- [`public/logo.tga`](../public/logo.tga) is a 256 x 256 uncompressed 32-bit TGA
  derivative of the approved PNG. It uses bottom-left origin, BGRA pixels, and
  8 alpha bits. The artwork is unchanged; Windows System.Drawing resizes it with
  high-quality bicubic interpolation and TileFlipXY edge sampling.
- `IronfurTracker.toc` links this file through `IconTexture`. It is included in
  the player package as an image resource, not in the TOC's Lua loading list.
- The full-resolution PNG and these screenshots are for the repository and
  addon listing. They are excluded from the game package.
- [`public/screenshots/default.png`](../public/screenshots/default.png),
  [`public/screenshots/wow-like.png`](../public/screenshots/wow-like.png), and
  [`public/screenshots/settings.png`](../public/screenshots/settings.png) are
  unchanged copies of `Default.png`, `WowLike.png`, and `Settings.png` from the
  user's Downloads folder. The originals remain there.

Input image 1: the actual World of Warcraft Ironfur spell icon, ability_druid_ironfur. This is the visual source to upscale and faithfully reinterpret, not a screenshot or a layout reference.
Primary request: create one polished high-resolution version of this icon with the addon's name on it. Aim for a 2048 x 2048 square PNG.
Artwork: preserve the source icon's recognizable close-up composition of overlapping, sharply pointed blue-black and silver metallic fur/armor plates, diagonal silver-white edge highlights, deep dark seams, and restrained icy cyan reflections. Reconstruct its tiny painted details cleanly at high resolution; keep the same visual identity and palette rather than inventing a bear mascot. The armored texture fills the square.
Typography: the exact addon name is "IRONFUR TRACKER". Put "IRONFUR" on the first line and "TRACKER" on the second, centered across the lower portion of the icon. Use strong, elegant fantasy serif lettering with crisp substantial strokes, silver/ivory faces and a dark outline or subtle shadow. Both words must be easy to read at thumbnail size. The title is part of the final logo, not an external caption. Give it enough dark separation from the texture and comfortable edge padding without covering all of the distinctive artwork.
Finish: high-quality hand-painted fantasy game icon, clean sharp edges, restrained depth and contrast, balanced composition. Opaque square background consistent with the original icon.
Constraints: exactly one finished logo; text spelled exactly as specified; preserve the source motif and blue-steel palette. No bear head, character, scenery, charts, extra slogans, additional brand names, watermark, mockup, or presentation sheet.
